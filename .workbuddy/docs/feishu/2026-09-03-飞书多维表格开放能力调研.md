## 二、多维表格（Base）核心能力

### 2.1 资源层级结构

```
多维表格 App (Base)
├── 数据表 (Table)
│   ├── 字段 (Field)
│   ├── 记录 (Record)
│   └── 视图 (View)
├── 仪表盘 (Dashboard)
│   └── 图表区块 (Block)
├── 表单 (Form)
│   └── 问题 (Question)
├── 工作流 (Workflow)
└── 角色权限 (Role & Permission)
```

### 2.3 字段类型支持

飞书多维表格支持丰富的字段类型：

| 类型 | 说明 | 典型场景 |
|------|------|---------|
| 文本 | 多行文本 | 标题、描述、备注 |
| 数字 | 支持格式化 | 价格、数量、评分 |
| 单选 | 下拉选择 | 任务状态、优先级 |
| 多选 | 多选标签 | 标签、分类 |
| 日期 | 时间戳 | 创建时间、截止日期 |
| 人员 | 飞书用户 | 负责人、协作者 |
| 链接 | URL | 文档链接、网页 |
| 附件 | 文件上传 | 截图、文档 |
| 公式 | 计算字段 | 自动计算、汇总 |
| 查找引用 | 跨表引用 | 关联数据 |
| 复选框 | 布尔值 | 完成状态 |
| 电话 | 电话号码 | 联系方式 |
| 地理位置 | 经纬度 | 位置信息 |

### 2.4 数据查询能力

```bash
# 使用 JSON DSL 进行高级查询
lark-cli base +data-query --base-token <token> --table-id <table_id> --params '{
  "filter": {
    "conjunction": "and",
    "conditions": [...]
  },
  "sort": [...],
  "aggregation": [...]
}'
```

支持：
- 复杂筛选条件（AND/OR 组合）
- 多字段排序
- 聚合统计（计数、求和、平均值等）
- 分页查询

## 三、与其他飞书产品的集成能力

### 3.1 云文档 (Docs)

```bash
# 创建文档
lark-cli docs +create --title "文档标题"

# 获取文档内容
lark-cli docs +fetch --document-id <doc_token>

# 更新文档
lark-cli docs +update --document-id <doc_token> --content "..."

# 搜索文档
lark-cli docs +search --query "关键词"
```

### 3.2 知识库 (Wiki)

```bash
# 列出知识空间
lark-cli wiki +space-list

# 列出节点
lark-cli wiki +node-list --space-id <space_id>

# 创建节点
lark-cli wiki +node-create --space-id <space_id> --title "节点标题"
```

### 3.3 云空间 (Drive)

```bash
# 上传文件
lark-cli drive +upload --local-path <file_path>

# 下载文件
lark-cli drive +download --file-token <token>

# 双向同步
lark-cli drive +sync --local-path <dir> --folder-token <token>

# 导入文件为云文档
lark-cli drive +import --local-path <file_path> --type bitable

# 导出云文档为本地文件
lark-cli drive +export --file-token <token> --type xlsx
```

### 3.4 日历 (Calendar)

```bash
# 查看日程
lark-cli calendar +agenda

# 创建日程
lark-cli calendar events create --data '{...}'

# 查询忙闲
lark-cli calendar freebusy list --params '{...}'
```

### 3.5 任务 (Task)

```bash
# 获取我的任务
lark-cli task +get-my-tasks

# 创建任务
lark-cli task +create --data '{...}'
```

### 3.6 即时通讯 (IM)

```bash
# 发送消息
lark-cli im +messages-send --chat-id <chat_id> --text "消息内容"

# 搜索聊天记录
lark-cli im +messages-search --query "关键词"
```

## 四、集成方案分析

### 4.1 方案对比

| 方案 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| **A. lark-cli 命令行调用** | 官方支持、功能完整、无需额外开发 | 依赖 CLI 工具、进程间通信 | ⭐⭐⭐⭐⭐ |
| **B. 飞书 OpenAPI HTTP 调用** | 灵活、可定制 | 需自行处理认证、错误处理 | ⭐⭐⭐ |
| **C. 飞书 SDK (Node.js)** | 类型安全、API 覆盖全 | 需要额外依赖、版本更新维护 | ⭐⭐⭐⭐ |

**推荐方案 A：lark-cli 命令行调用**

理由：
1. 已安装且配置完成，可直接使用
2. 命令覆盖完整，包括快捷命令和原始 API
3. 支持 JSON 输出，易于解析
4. 与 Orca 的日历集成模式一致（CLI 工具 + 面板页面）

### 5.2 命令行封装

```typescript
// 封装 lark-cli 调用
class LarkBitableClient {
  // 获取表格列表
  async listTables(baseToken: string): Promise<BitableTable[]> {
    const result = await exec('lark-cli base +table-list', {
      params: { base_token: baseToken }
    });
    return JSON.parse(result);
  }

  // 获取记录列表
  async listRecords(
    baseToken: string,
    tableId: string,
    options?: { filter?: string; sort?: string; limit?: number }
  ): Promise<BitableRecord[]> {
    const result = await exec('lark-cli base +record-list', {
      params: {
        base_token: baseToken,
        table_id: tableId,
        ...options
      }
    });
    return JSON.parse(result);
  }
}
```

## 六、权限与安全考虑

### 6.1 所需权限

| 权限 | 用途 | 必要性 |
|------|------|--------|
| `bitable:app:readonly` | 读取多维表格 | 必需 |
| `bitable:app` | 创建/编辑多维表格 | 可选 |
| `drive:file:readonly` | 读取云空间文件 | 推荐 |
| `docx:document:readonly` | 读取文档内容 | 推荐 |

### 6.2 安全建议

1. **最小权限原则**：仅申请必要的 API 权限
2. **Token 安全**：使用加密存储，避免明文保存
3. **操作审计**：记录关键操作（删除、修改）日志
4. **用户授权**：敏感操作需用户确认

## 七、风险与挑战

| 风险 | 影响 | 应对策略 |
|------|------|---------|
| API 限流 | 高频操作被限流 | 实现重试机制、批量操作 |
| 数据量大 | 查询响应慢 | 分页加载、缓存策略 |
| 字段类型复杂 | 渲染困难 | 渐进式支持，优先核心类型 |
| 跨平台兼容 | Windows/macOS/Linux | 使用 lark-cli 跨平台特性 |
