# 移除 Gitee 集成影响说明

## 背景

用户决定不再集成 Gitee，需要完全移除 Gitee 相关代码。Gitee 集成是第一个二开任务（PR #1 已合入 custom），采用 copy 架构（独立重写不复用 GitHub 渲染），代码收敛到独立文件，删除风险低。

## 风险评估

**风险等级：低**

- ✅ Gitee 代码完全独立（copy 架构，不复用 GitHub 渲染）
- ✅ 无核心功能依赖 Gitee
- ✅ 上游同步零冲突风险
- ✅ 删除后不影响其他 provider（GitHub/GitLab/Linear/Jira）
