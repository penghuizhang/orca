# 完成通知「有提示音、无右侧横幅、测试也不弹」排查说明

日期：2026-08-24
类型：诊断 / 影响说明（纯排查，未改动 Orca 代码）

## 现象
- 任务（agent）完成后能听到通知提示音，但屏幕右上角无系统横幅弹窗。
- Settings → Notifications 的「Send Test Notification」测试通知同样不弹。

## 结论（根因）
运行中的 app bundle（orca-s 或官方 orca）在 **macOS 系统设置 → 通知** 里的「提醒样式」被设为 **None**。

授权状态为 `authorized`（通过），但 `style=None` 时 macOS 仍返回 authorized、却什么都不渲染。这与「能听到声音、无横幅、测试也不弹」完全吻合，且 Orca 自带权限卡片 `MacNotificationPermissionCard` 会**误报「已送达/delivered」**，误导排查方向。

## 代码证据（两条独立链路）
- 横幅 = main 进程 `notifications:dispatch`（`src/main/ipc/notifications.ts:107`）→ 过 `enabled` / `agentTaskComplete` / `suppressWhenFocused` / `cooldown` / `Notification.isSupported` 门禁 → macOS 下读 `readNotificationAuthorizationStatus()`，仅 `authorized` 才 `deliverNativeNotification()`（`src/main/ipc/native-notification-delivery.ts:20`）→ `new Notification(...).show()` 交 macOS 渲染。
- 声音 = renderer 端 `use-notification-dispatch.ts:232` 在 `result.delivered === true` 时调 `playDesktopNotificationSound()`，自定义声音走 `silent=true` + Orca 自己 `playSound`，**不依赖 macOS 横幅**。

**决定性推论**：听到自定义提示音 ⇒ `result.delivered === true` ⇒ 已越过全部门禁且 macOS 授权 = `authorized`。故「有声无横幅」唯一解释为授权通过但**提醒样式 = None**。

若无声也无横幅，才是 `denied` / `not-determined`（main 返回 `blocked-by-system`，renderer 会弹 `showBlockedNotificationFallbackToast` 兜底）——有声这一事实本身已排除「未授权」。

> 补充排除：`Suppress While Focused`（默认 true）若触发会返回 `suppressed-focus`，声音同样不响；用户有声 ⇒ 当时未聚焦该工作树或已关该开关，非主因。

## 修复（用户侧，无需改代码）
1. 系统设置 → 通知 → 找到正在运行的 app：
   - orca-s → `com.penghuizhang.orca-s`（adhoc 自签，每次重打包样式易被重置为 None，复发率高）
   - 官方 orca → Orca
2. 确认「允许通知」开。
3. **提醒样式选「横幅」或「提醒」（勿选 None）**——横幅不弹的直接开关。
4. 关掉再点一次 Send Test Notification 验证；仍不弹则退出 app 重开让 bundle 重新注册通知。
