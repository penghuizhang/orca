# 记忆目录优化方案（2026-09-04）

## 问题背景

当前 `.workbuddy/memory/` 存在以下问题：
- 28 个文件堆在一级目录，难以快速定位
- 日记忆与功能记忆混放
- 命名前缀混乱（orca-/zcode-/无前缀）
- 跨工程通用知识与项目专属知识混杂

## 优化目标

1. 减少文件数量：28 → ~12 个
2. 按物理目录天然分类
3. 统一命名规范
4. 分离通用知识与项目专属知识

## 具体操作

### 1. 分离日记忆到子目录

```
.workbuddy/memory/
├── daily/                    ← 新增
│   ├── 2026-09-03.md
│   └── 2026-09-04.md
├── MEMORY.md
└── *.md                      ← 功能记忆
```
