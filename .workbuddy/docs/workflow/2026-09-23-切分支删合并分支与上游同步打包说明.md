## 七、打包返工记录

- 首次 `build-orca-s --install` **实际失败**（被 `| tail` 管道掩盖成假 exit 0）：`build:mobile-web` 按上游新链路跑 `build-mobile-web-app-bundle.mjs`，419 个 `Could not resolve "expo-router"/"react-native-web"`。

- 教训已蒸馏：打包前清单 +2 条（mobile 独立 workspace 需单独装；勿用管道退出码判成败）。

### 二次返工：.DS_Store 撞 buildId CRLF 校验

- 装完 mobile 依赖后 mobile bundle 构建成功，但 `verify-mobile-web-app-bundle` 报 `CRLF in mobile web source: .DS_Store`（exit 1）。
- 根因：`mobile/src/.DS_Store`、`mobile/app/.DS_Store` 两个 macOS 垃圾文件（gitignored ⇒ verify-features 干净检查看不见）在 `.gitattributes` `eol=lf` 钉扎的树内，二进制含 0x0D0x0A 被 CRLF 扫描误伤。
- 修复：`find mobile/{src,app,web-entry} -name .DS_Store -delete` → 重跑。
- 教训：**gitignored 的垃圾文件能绕过"工作区干净"门禁、却躲不过字节级校验**；源码树里见到 .DS_Store 顺手删。
