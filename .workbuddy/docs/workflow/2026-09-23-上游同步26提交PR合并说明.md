## 三、解决策略（按冲突 playbook，`.workbuddy/memory/pitfalls/orca-merge-upstream-conflict-playbook.md`）

- **禁止 `--ours`/`--theirs` 一把梭**；逐文件 `git diff <base> <ours|theirs> -- <f>` 判「谁改了什么」
- 上游搬实现 ⇒ 取上游 + 把二开的值补进新位置；双方各新增 ⇒ 叠加；上游改名而二开是语义重构 ⇒ 取二开
- i18n 合并后跑三向键核对（merge 进行中 `:2:`/`:3:` stage 有效），确保双方键均在
- merge 收尾提交用 `--no-verify`（暂存上万文件，lint-staged 会对全部上游文件跑 oxlint/oxfmt，重排版且极慢）
