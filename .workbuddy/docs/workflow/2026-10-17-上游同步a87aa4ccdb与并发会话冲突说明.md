## 环境侧两个实测结论（省时间）

1. **Electron 二进制下载**：走 GitHub release 实测 ~50KB/s（一次 40 分钟没下完，超时被 kill），
   走 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` + `ELECTRON_CUSTOM_DIR="{{ version }}"`
   + `ELECTRON_CACHE=~/Library/Caches/electron` 实测 **432KB/s，3 分钟下完 121MB**。
   `config/scripts/install-electron-package-binary.mjs` 用 `@electron/get`，认这两个环境变量。
2. **上游移除了 `vscode-textmate` 依赖**（改用 `@shikijs/vscode-textmate`）并把 vitest 提到
   `5.0.5`。二开侧源码同步到上游版后自然消失，不需要自己加回。
