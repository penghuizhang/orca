# Orca 移动遥控云中转（线路 B）配置方案与运行手册

日期：2026-08-17
类型：配置实施（frp 云中转，零代码改动）
分支：custom（与代码改动无关）

## 1. 结论摘要

- 目标：手机 App 出门在外也能遥控本地桌面 Orca（fork 版 orca-s），流量经自家云服务器中转。
- 方案：**frp 反向隧道（透明 TCP 转发，线路 B）**。云服务器 120.26.183.77（Rocky Linux 10 阿里云）跑 frps，本地 Mac 跑 frpc，把 `127.0.0.1:6768`（orca-s 的 WebSocket RPC 端口）映射到云服务器公网端口 **8095**。
- 端口 8095 按 port_registry 规则分配（backend 段 8000-8999，MAX+1=8095，已登记，`backend_next` 推进到 8096）。
- **一条链路**：手机 → `ws://120.26.183.77:8095` → frps（云 8095）→ 隧道 → frpc（Mac）→ `127.0.0.1:6768`（orca-s）。
- 手机侧鉴权仍是 Orca 自家的设备令牌 + Curve25519 E2EE，frp 只透传字节，不改协议不动代码。

## 2. 已完成的配置（全部生效验证通过）

### 云服务器 120.26.183.77（root SSH 直连）

- 二进制：`/usr/local/frp/frps`（v0.68.0，与本地 frpc 同版本），systemd 单元 `/etc/systemd/system/frps.service`。
- 配置 `/etc/frp/frps.toml`：

```toml
bindPort = 7000

auth.method = "token"
auth.token = "6ca6b27ced99e2ab5a5444e23be1632b2684d5eb0613fcec"

log.to = "/var/log/frps.log"
log.level = "info"
log.maxDays = 7
```

- 端口：控制口 7000（Mac frpc 出站连接）、代理口 8095（手机 ws 直连）。firewalld 已永久开放 `7000/tcp`、`8095/tcp` 并 reload。
- 遗留：`/usr/local/bin/frps`（4 月 11 日旧二进制，曾占 7000 端口 128 天）已废弃，systemd 现指向 `/usr/local/frp/frps`；旧文件未删除，保留观察。

### 本地 Mac

- 配置 `/opt/homebrew/etc/frp/frpc.toml`（brew services 读取路径；原测试配置已备份为 `frpc.toml.bak-20260817`）：

```toml
serverAddr = "120.26.183.77"
serverPort = 7000
loginFailExit = false

auth.method = "token"
auth.token = "6ca6b27ced99e2ab5a5444e23be1632b2684d5eb0613fcec"

[[proxies]]
name = "orca-mobile-6768"
type = "tcp"
localIP = "127.0.0.1"
localPort = 6768
remotePort = 8095
```

- 由 `brew services start frpc` 常驻（keep_alive，开机自启），日志 `/opt/homebrew/var/log/frpc.log`。
- 注意：隧道固定指向 `127.0.0.1:6768`，即 **fork 版 orca-s**（它占 localhost 6768；官方 Orca 占 `*:6768`，不冲突）。

## 3. 验证记录

- 云上 `ss -tlnp`：frps 监听 `*:7000` 与 `*:8095`；frps 日志显示 Mac frpc（darwin/arm64，公网 171.12.3.106）login success、`orca-mobile-6768` tcp proxy 建立成功。
- 端到端：Mac 直连云 8095 发 WS 升级请求，连接保持无重置（透明 TCP 链到本地 orca-s；orca-s 对裸升级不回应是正常行为，它期待自家 E2EE 帧）。

## 4. 手机接入步骤（剩余待用户操作）

1. **阿里云控制台 → 安全组**：放行入方向 TCP **8095** 与 **7000**（firewalld 只放行了 OS 层，安全组是云厂商层，必须单独开）。
2. 桌面 Orca（orca-s）→ **Settings → Mobile** → 连接方式选 **LAN / 本地** → 网络地址选**自定义 (custom address)**，填：
   `ws://120.26.183.77:8095`
3. 生成的二维码会自动通告该地址，手机 App 扫码配对即可；或手机端已配对 host 手动改地址为 `ws://120.26.183.77:8095`（App 内 `host 编辑` 入口）。

## 5. 风险与后续硬化（可选）

- 当前手机↔云是明文 `ws://`：Orca 内容本身有 E2EE，但设备令牌在链路上可见。**建议升级 wss**（需在云上配域名 + 证书，nginx/caddy 做 TLS 终结再转发 8095，或 frp 开 `transport.tls` 加密 frpc↔frps 段）；自签证书不可用（RN 不固定自签）。
- iOS 端 ATS 可能拦截明文 `ws://`（Android 已确认 usesCleartextTraffic 放行）；若 iOS 连不上，wss 升级是必选而非可选。
- 云上旧 frps 二进制 `/usr/local/bin/frps` 确认无用后可删除。

## 6. 日常维护速查

- 本地：`brew services restart frpc`；看日志 `tail -f /opt/homebrew/var/log/frpc.log`。
- 云端：`systemctl restart frps`；看日志 `tail -f /var/log/frps.log`。
- 改端口/地址只需改两份 toml 后重启两侧服务；token 如需轮换，两端同步改。
