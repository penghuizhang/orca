# 日历功能优化：点击建条目 + 国际化补全（设计/影响说明）

- 日期：2026-08-16
- 状态：**已实施**（用户口述 3 个问题，均为明确修复项）
- 分支：`calendar-feature`
- 前置文档：`docs/2026-08-16-日历功能设计方案.md`（一期实施已完成，本次为优化轮）

## 1. 问题清单（用户反馈 + 截图核实）

| # | 问题 | 截图/代码核实 |
|---|---|---|
| 1 | 点击月视图日期格子不能弹窗补充内容 | `calendar-month-grid.tsx` 单元格 onClick 只调 `onSelectDate`，无弹窗 |
| 2 | 日历界面未遵循国际化，全英文 | zh.json **整个 `auto.components.calendar.*` 子树缺失**（en.json 已全）；translate 全部走英文 fallback |
| 3 | 左侧边栏日历入口英文 | zh.json 缺 `auto.components.sidebar.SidebarNav.calendar` 键（en.json 已有） |

另核实到的键冲突 bug：en.json `auto.components.calendar.title = "Calendar"` 同时被两处复用——页头标题（合理）与对话框「标题」表单标签（英文界面下标签错误显示为 "Calendar"），须拆键。

## 2. 方案

1. **点击格子建条目**：`CalendarMonthGrid` 新增 `onRequestCreate(dateKey)` prop；单元格 onClick = 选中该日 + 打开新建弹窗（默认日期=所点格子）。格内条目 chip 的编辑行为不变（已有 stopPropagation）。侧栏迷你月历点击仍只选中（浏览不打断）。
2. **国际化补 zh**：zh.json 补 `auto.components.calendar.*` 全子树（34 键）+ `SidebarNav.calendar`；en.json 拆键 `pageTitle`（页头）、`title` 改回 `"Title"`；`deleteEntryDescription` 从 JSX 拼接改为 `{{title}}` 插值（zh 用「确定删除「{{title}}」？」）。es/ja/ko 缺键按项目惯例回退英文（校验脚本允许）。
3. 代码改动均走现有 `translate()`，不新增硬编码用户可见字符串（`verify:localization-coverage` 需过）。

- `src/renderer/src/components/calendar/calendar-month-grid.tsx`（+prop、+onClick 动作）

## 4. 约束清单（实施自查）

1. 【约束-i18n 一致性】zh 键必须与 en 键一一对应，无多余键（校验脚本 extraInLocale=0）；插值变量与 en 完全一致（{{title}}/{{count}}）。
2. 【约束-硬编码】不新增 translate() 之外的用户可见字符串。
3. 【约束-行为】格子点击=选中+弹窗；chip 点击=编辑（stopPropagation 保留）；侧栏迷你月历=仅选中。
4. 【约束-验证】`verify:localization-catalog`、`verify:localization-extraction`、`verify:localization-coverage` 全过；typecheck + 相关单测 + oxlint/oxfmt。
5. 【约束-行数】不触碰近上限文件，不写 max-lines disable。

## 5. 验收方式

`pnpm dev` 中文环境：① 点任意日期格 → 弹新建弹窗且日期=所点日；② 日历页全部文案中文（日历/今天/新建条目/分类/会议/功能点/里程碑/其他/无标题/删除确认等）；③ 侧边栏入口显示「日历」；④ 英文环境回归（en 键无回归，标题标签显示 Title）。
