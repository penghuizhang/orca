## 2. 数据层设计（纯函数，可单测）

### 2.1 农历扩展（`lunar-date.ts` 扩展，不超 300 行）
- `getLunarYearInfo(date): { year, month, day, isLeapMonth } | null`——暴露农历**年**（现 `getLunarMonthDay` 不返回年），重构复用内部步行逻辑
- `lunarToGregorianDate(lunarYear, month, day, isLeapMonth): Date | null`——反推（epoch `1900-01-31` 累加天数），供农历排期映射
- `getLunarYearName(year): string`——天干地支（2026 → 丙午年）
- 现有 `getLunarDayText` 保留（网格农历日小字）

### 2.2 二十四节气（新文件 `solar-term.ts`）
- 标准分钟偏移算法：`Date.UTC(1900,0,6,2,5) + 31556925974.7*(y-1900) + sTermInfo[n]*60000`，n=0..23 对应 小寒..冬至
- `getSolarTermName(date): string | null`（该日恰为节气日返回名称）
- 名称中文（专有名词，与农历一致，所有语言环境不变）；单测用已知日期验证（2026 春分 3/20、清明 4/5、2026 冬至 12/22 等）

### 2.3 传统节日（新文件 `festival.ts`）
- 农历固定：春节 1/1、元宵 1/15、龙抬头 2/2、端午 5/5、七夕 7/7、中元 7/15、中秋 8/15、重阳 9/9、腊八 12/8、小年 12/23、除夕=腊月最后一天（29/30 动态）
- `getFestivalName(date): string | null`
- **`getDayLabel(date): string | null`**：`节日 > 节气 > 农历日` 优先级，供网格右上角小字

### 2.4 法定节假日休/班（新文件 `holiday-data.ts`）
- `OFFICIAL_HOLIDAYS: Record<string, 'rest' | 'work'>`（YYYY-MM-DD → 例外状态，只存假日与补班）
- `getDayStatus(date): 'rest' | 'work' | null`：表内 → 表值；周末 → 'rest'；其余 null（普通工作日）
- 2026 数据源：**gov.cn 通知原文**（已抓取，见 §3）；2025 为已公布公开事实（覆盖 2026-01 视图的相邻月与历史导航）；2027 待官方发布后逐年补充
- 补班日（周末上班）**移除周末底纹**，显示「班」徽标——避免「底纹说休息、徽标说上班」的矛盾

### 2.5 农历日期排期（shared 数据模型）
- `CalendarEntry` 加 `lunarRepeat: { month: number; day: number } | null`（一期不支持闰月；normalize 缺省 null，旧数据安全）
- `calendar-time.ts` 加 `entriesByDateKey(entries, dateKey, viewYear)`：solar 条目按 date 分桶；lunarRepeat 条目按 **viewYear 对应公历日期**（`lunarToGregorianDate`）分桶；该农历日当年不存在（如腊月三十小月）→ 当年不显示
- 对话框「农历日期」开关 → 月/日 Select；保存时 `date` 存首次对应公历日期（锚点），`lunarRepeat` 存排期规则

## 4. UI 设计

### 4.1 月网格 cell（`calendar-month-grid.tsx`，控制 <300 行）
```
┌─────────────────────────────┐
│ [休] 16  立秋                │ ← 左上：休/班徽标 + 日期号；右上：节日>节气>农历日
│ ● 09:30 周会                 │ ← 条目 chips（不变）
└─────────────────────────────┘
```
- **周末**：周六/日列 `bg-muted/40` 底纹（补班日移除）；表头 六/日 `text-destructive`
- **跨月**：非当月 cell `bg-muted/20` 底纹 + 现有 muted 日期数字（条目 chips 降 opacity）
- **休/班徽标**：12px 小标签，仅特殊日显示——假日（周末或工作日）→「休」（text-destructive 红）；补班 →「班」（muted 灰）；普通周末靠底纹表达不重复徽标
- **右上角文本**：`getDayLabel`（节日>节气>农历日）；「显示农历」关闭时隐藏（休/班徽标不受影响）
- 今日红圈、选中高亮、chip 编辑行为全部保留

### 4.2 日面板（`calendar-day-panel.tsx`）

### 4.3 侧栏（`calendar-side-panel.tsx`）

### 4.4 对话框（`calendar-entry-dialog.tsx`）

## 7c. 验收微调：周末/工作日色彩对比增强（2026-08-16 用户反馈）

- 反馈：工作日与非工作日对比不明显、看着费力（原 `bg-muted/40` 在浅色主题下几乎不可见——muted=#f5f5f5 接近背景白）。
- 调整（全部 token 内，无新色值）：① 周末格子底纹 `bg-muted/40` → `bg-muted-foreground/10 dark:bg-muted-foreground/15`；② 表头六/日红字加粗（工作日表头保持 muted）；③ 周末日期数字 `text-destructive/80` → 全红加粗；④ 休/班徽标加浅色底 pill（bg-destructive/10、bg-muted-foreground/10）；⑤ 迷你月历周末数字全红加粗。
- 保留语义：补班日仍无周末底纹（班徽标表述真相）；跨月弱化/选中/今天红圈优先级不变。
- 验证：typecheck:web、oxlint、oxfmt 全绿；HMR 即时生效待用户目视确认。

## 7d. 验收微调 2：连休节假日横条 + 节日名（2026-08-16 用户反馈+参考截图）

- 反馈：连休（如国庆 10/1-10/7）只标「休」不直观，看不出连着休几天、不知道是哪个节日（参考图：节假日以跨格横条显示节日名）。
- 方案：① `holiday-data.ts` 新增 `HOLIDAY_BLOCKS`（2025/2026 各法定假日段 start/end + 段名：元旦/春节/清明节/劳动节/端午节/中秋节/国庆节）+ `getHolidayBlock(dateKey)`（返回段名+总天数）；② 网格：段内格子 `pt-5` 让出顶部空间，**段首格子渲染跨格横条**（absolute + `width: calc(N*100% + (N-1)px)` 跨越连续 N 格），显示「国庆节 · 7天」；跨行段（春节 9 天跨行）按行拆分，每行片段独立渲染；③ 纯周末段不显示横条（无法定假日）；④ 每格「休/班」徽标保留；⑤ i18n `holidayDays` 复数变体（en one/other、zh 单值）。
- 语义：补班日（10/10）无横条；横条不受「显示农历」开关影响（法定假日信息）；跨月弱化/选中/今天态不冲突。
- 验证：单测 55/55（getHolidayBlock 段名/天数/补班日 null）、typecheck:web、oxlint、oxfmt、localization 三检查全绿；dev 已重启待目视确认。
