# 新增 ZCode 智能体类型设计方案

日期：2026-08-16
状态：待评审
分支：feature/zcode-agent → custom（PR）

## 1. 背景与目标

Orca 已内置 39 种 CLI 智能体（`TuiAgent` 联合类型），包括 Claude Code、OpenAI Codex、OpenCode、Gemini CLI 等。现需新增 **ZCode** 作为完整类型：

- 本地已安装：`/Users/zhangpenghui/.local/bin/zcode`（npm 全局包 `zcode-app-cli` 3.7.7-13，runtime 0.16.3，kingsword09/zcode-cli，opencode 的 fork）
- 无参数运行 `zcode` 打开全屏 TUI；配置在 `~/.zcode/cli/config.json`
- 支持 `--resume <sessionId>`（sess_...）、`-c/--continue`、`/resume` slash 命令
- hooks 为 opencode 风格（SessionStart/UserPromptSubmit/PreToolUse/PostToolUse/Stop），默认 `enabled: false`

目标：新工作区 agent 选择器、tab 快速启动、设置面板（默认 agent/禁用）、图标、标题识别、telemetry 全链路可用，与既有 39 种 agent 体验一致。

## 2. 现有接入机制调研（如何"注册"一个 agent）

核心是一张"注册表 + 若干派生表"，绝大多数位置**由类型完备性强制**（`satisfies Record<TuiAgent, …>` / `Record<TuiAgent, true>`），编译期即可发现漏改：

## 3. 具体改动设计

### 3.1 类型与配置（shared 层）

**`src/shared/tui-agent.ts`**：联合类型追加

```ts
| 'zcode' // ZCode (zcode CLI)
```

**`src/shared/tui-agent-config.ts`**：

```ts
zcode: {
  detectCmd: 'zcode',
  launchCmd: 'zcode',
  expectedProcess: 'zcode',
  // Why: zcode 的 --prompt / -p(--print) 均为 headless 一次性执行并退出（同 ante 的 --prompt 语义），
  // 不能用作启动注入；TUI 无 positional prompt，故启动后粘贴。
  promptInjectionMode: 'stdin-after-start'
}
```

> ⚠️ 待实测（实施时验证）：zcode TUI 是否支持 bracketed paste + 光标就绪信号（opencode fork，大概率支持 `render-cursor-after-bracketed-paste`）；若实测可用再补 `draftPasteReadySignal`，否则维持默认粘贴窗口。

**`src/shared/tui-agent-display-names.ts`**：`zcode: 'ZCode'`（ALL_TUI_AGENTS 自动含 zcode）。

**`src/shared/telemetry-events.ts`**：`AGENT_KIND_VALUES` 追加 `'zcode'`。

**`src/shared/agent-kind.ts`**：映射表追加 `zcode: 'zcode'`。

**`src/shared/agent-type-label.ts`**：`zcode: 'ZCode'`。

**`src/shared/agent-name-token-match.ts`**：`AGENT_NAMES` 追加 `'zcode'`（整词匹配，`zcode` 不会误命中普通 shell 标题，安全）。

**`src/shared/tui-agent-selection.ts`**：`TUI_AGENT_AUTO_PICK_ORDER` 中 `opencode` 之后插入 `'zcode'`（同生态 fork，就近）。

**`src/shared/skills-cli-agent-keys.ts`**：`zcode: null`（社区 skills CLI 的 `--agent` 命名空间未确认支持 zcode，按注释约定「不确定即 null 丢弃」，避免 exit 1）。

### 3.2 renderer 层（目录/图标）

**`src/renderer/src/lib/agent-catalog.tsx`**：新增条目（opencode 条目后）：

```tsx
{
  id: 'zcode',
  label: translate('auto.lib.agent.catalog.<新键>', 'ZCode'),
  cmd: 'zcode',
  faviconDomain: 'z.ai',
  homepageUrl: 'https://github.com/kingsword09/zcode-cli'
}
```

**`src/renderer/src/lib/agent-icon-glyphs.tsx`**：新增 `ZCodeIcon`（手绘 "Z" 字形 SVG，currentColor 适配双主题，风格对齐 OpenCodeIcon 512 canvas）。

**`src/renderer/src/lib/agent-catalog.tsx` AgentIcon**：`if (agent === 'zcode') return <ZCodeIcon size={size} />`。

**`src/renderer/src/lib/agent-status.ts`**：`ICONABLE_AGENT_TYPES` 追加 `zcode: true`。

### 3.3 会话恢复（推荐含入一期）

zcode 支持 `--resume <sessionId>`（sess_...），对齐 opencode 的 `--session`：

**`src/shared/agent-session-resume.ts`**：
- `RESUMABLE_TUI_AGENTS` 追加 `'zcode'`
- `getAgentResumeArgv` 追加：

```ts
case 'zcode':
  return providerSession.key === 'session_id' ? ['zcode', '--resume', id] : null
```

- `extractAgentProviderSession` 的 `case 'zcode'`：**先返回 null**（不自动提取）。原因：Orca 对 opencode 的 sessionID 提取依赖注入的 hook plugin（`src/main/opencode/hook-service.ts`，写 `orca-opencode-status.js` 到 opencode 插件目录 + `/hook/opencode` 端点）；zcode 的插件目录/配置与 opencode 不同（`~/.zcode/plugin-workspace`），hook 输出格式需实测。一期保证「手动/续期恢复」可用（`zcode --resume`），hook 自动提取列为二期。

### 3.4 i18n

- `en.json`：`pnpm sync`（或既有 i18n sync 脚本）自动补 `auto.lib.agent.catalog.<hash>` 键
- `zh.json` / `es.json` / `ja.json` / `ko.json`：手工补键（`"ZCode"` / `"ZCode"` / `"ZCode"` / `"ZCode"`），缺键时看英文 fallback

### 3.5 测试（tsc + 完备性强制自动暴露，逐项修复）

- `agent-kind.test.ts`、`skills-cli-agent-keys.test.ts`、`tui-agent-startup.test.ts`：完备性断言自动要求补 zcode 条目
- `keybindings-default-bindings.test.ts`、`orca-runtime.test.ts`、`discovery.test.ts`：agent 列表相关断言可能需补

## 5. 验收标准

1. `pnpm lint && tsc` 全绿；相关单测通过
2. 新工作区 agent 选择器出现 ZCode，图标/名称正确；tab 快速启动输入 `zcode` 可模糊命中
3. 设置面板默认 agent 可选 ZCode；未安装机器上检测为未安装（不出现或提示安装）
4. Orca 内启动 `zcode` 进入 TUI；从外部运行 `zcode --resume <id>` 可恢复会话
5. telemetry 事件 agent_kind=zcode（本地验证事件文件）

## 6. 约束清单（实施自查）

- 【约束】所有 `satisfies Record<TuiAgent, …>` 完备 map 必须补条目，交给 tsc 兜底
- 【约束】i18n：en.json 由 sync 自动补，zh/es/ja/ko 手工补，不得只改 en
- 【约束】promptInjectionMode 不得选 `flag-prompt`/`argv`（zcode 无 TUI positional prompt，--prompt 会 headless 退出）；用 `stdin-after-start`，实测后再加 draftPasteReadySignal
- 【约束】不新增 max-lines disable（AGENTS.md 规则）；注释只写 WHY
- 【约束】提交大 JSON（en.json 等）后必须 json.load 校验（历史坑：oxfmt 损坏 en.json 导致打包失败）
- 【约束】功能改动走 feature 分支 + PR → custom，不直推
- 【约束】跨平台：detectCmd/launchCmd 均为 `zcode` 单一二进制名，不引入平台分支
