# zcode 使用量统计补充设计

## 背景

用户发现 Orca 的"统计和使用情况"页面没有统计到 zcode 的用量信息。

## 现状分析

### 代码结构

1. **StatsPane.tsx**（统计和使用情况页面）只跟踪 3 个 provider：
   - Claude
   - Codex
   - OpenCode

2. **zcode** 虽然在 `agent-kind.ts` 和 `telemetry-property-schemas.ts` 中注册了，但**没有独立的 usage provider**

3. **zcode 使用 opencode 的 API**：
   - zcode 使用 opencode 提供的模型
   - zcode 的使用量可能已经被计入 opencode 的统计中，但没有被区分显示

### 关键代码位置

- `src/renderer/src/components/stats/StatsPane.tsx:55` - UsageTab 类型只包含 overview/claude/codex/opencode/grok
- `src/renderer/src/components/stats/UsageOverviewPane.tsx` - 只有 claude/codex/opencode 的状态
- `src/renderer/src/store/slices/usage-provider-slices.ts` - 只有 claude/codex/opencode 的 slice

## 方案选择

### 方案 A：zcode 使用量计入 opencode（推荐）

**理由**：
- zcode 使用 opencode 的 API，使用量本质上是 opencode 的使用量
- 不需要额外的 API 调用或数据源
- 实现简单，只需要在 UI 中添加说明

**实现**：
1. 在 StatsPane.tsx 中添加说明，告知用户 zcode 的使用量包含在 OpenCode 统计中
2. 或者在 OpenCodeUsagePane.tsx 中添加 zcode 相关的说明

### 方案 B：单独追踪 zcode 的使用量

**理由**：
- 如果需要区分 zcode 和 opencode 的使用量
- 需要独立的 usage provider

**实现**：
1. 创建 `src/shared/zcode-usage-types.ts`（类型定义）
2. 创建 `src/main/rate-limits/zcode-usage-fetcher.ts`（数据获取）
3. 在 `src/renderer/src/store/slices/usage-provider-slices.ts` 中添加 zcode slice
4. 在 `src/renderer/src/components/stats/StatsPane.tsx` 中添加 zcode 选项卡
5. 在 `src/renderer/src/components/stats/UsageOverviewPane.tsx` 中添加 zcode 状态

## 推荐方案

**推荐方案 A**，因为：
1. zcode 使用 opencode 的 API，使用量本质上是 opencode 的使用量
2. 不需要额外的 API 调用或数据源
3. 实现简单，用户易于理解

## 影响范围

- 仅影响 UI 层面的显示
- 不影响底层数据收集
- 用户体验提升：明确告知 zcode 使用量的统计方式
