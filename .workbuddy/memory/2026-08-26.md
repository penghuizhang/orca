# 2026-08-26

## 需求：让外部 CLI(zcode/codex) 驱动 orca 浏览器标签页

**用户场景**：一个 worktree 下同时开终端标签页(zcode/codex CLI) + 浏览器标签页(测试网站)，希望 CLI agent 能读页面内容、点击、填表、输入，用于「边看源码边看网站、自动出文档」的浏览器自动化场景。

### 调研结论（关键）
- orca 浏览器自动化核心能力**已完整存在**，只对内置 agent 开放，外部 CLI 进不来。缺口仅是「出口」。
- 链路：`RuntimeBrowserCommands`(src/main/runtime/orca-runtime-browser.ts，40+ 方法，支持 worktree+page 定位) → `AgentBrowserBridge`/`CdpBridge` → orca 浏览器 webview 的 CDP。
- 浏览器标签页用 Electron `<webview>`，main 持有完整 `webContents`+`debugger` 权限；安全隔离(nodeIntegration=false/contextIsolation/sandbox)到位。
- `@modelcontextprotocol/sdk@1.30.0` 已在 node_modules，提供 `Server`+`StreamableHTTPServerTransport`+`SSEServerTransport`。orca 现有 mcp-config 仅作**客户端**读外部配置，不 host server。

### 方案拍板（用户已选）
- 集成方式：**orca 内置 MCP Server**（薄适配包住 RuntimeBrowserCommands，零重造）。
- 传输：**本地 HTTP/SSE（Streamable HTTP，127.0.0.1:/mcp，Bearer Token）**。
- 首版范围：**只读优先**（tab_list/tab_current/snapshot/screenshot/evaluate），验证后再补交互(navigate/click/fill/type/...)。

### 设计文档
`docs/2026-08-26-浏览器自动化MCP服务设计方案.md`
新增模块：`src/main/browser/mcp/{browser-mcp-server,browser-mcp-http-transport,browser-mcp-tool-definitions,browser-mcp-settings}.ts` + 设置项(默认关闭)+Settings UI(复制 MCP 配置 JSON)。

### 约束（实施逐条自查，详见设计文档 §10）
- HTTP 仅绑 127.0.0.1；默认关闭+Bearer Token(safeStorage)；不改远程 wire；复用 RuntimeBrowserCommands 不新建浏览器逻辑；新增文件不加 max-lines disable、命名具体；i18n 补 zh 键；大 payload 设上限；端口冲突回退。
- 已知限制：SSH/远程场景(或ca 远程+CLI 本地) 127.0.0.1 不可达，本次不解决（后续可走现有远程隧道）。

## 实施：日历「工作清单」历史周/月查看与复制优化（2026-08-26，已实施）

### 问题
V2 的「复制本周清单」+ 底部概览条只能看 `weekRangeDates(selectedDateKey)`（选中日所在周），无跨周/历史周月/整体区间视图。

### 关键事实
`CalendarPage` 已 `window.api.calendar.list()` 全量加载 `entries`，`buildWeekListMarkdown`/`summarizeWeekHours`/`weekRangeDates` 本质只依赖有序 dateKey 列表 → **本次是纯 renderer 展示层范围泛化，零 schema/IPC/main 改动**。

### 方案要点
- 新增 `WorkListRange`（week/month/custom）+ `rangeDates/rangeLabel/shiftRange`（落 calendar-time.ts）。
- 底部概览条升为「区间可切换概览」：紧凑下拉（本周/上周/本月/上月/自定义）+ 分类计数 + 合计工时 + 「复制清单」。
- 对话框升为「工作清单」：顶部区间选择器 + ◀▶ 翻期 + 自定义日期输入，按天 Markdown 预览任意区间，复制到剪贴板。
- 区间状态提到 CalendarPage 共享；点某天不再改概览条区间（与选中日解耦）。
- 复用 `buildWeekListMarkdown`(改名 buildWorkListMarkdown)/`summarizeWeekHours`/分类计数逻辑；沿用 V2 简化清单格式（仅 `1. 标题`）。
- 组件：新增 calendar-range-picker.tsx；calendar-week-summary.tsx→calendar-range-summary.tsx；calendar-week-list-dialog.tsx→calendar-work-list-dialog.tsx；calendar-week-list.ts→calendar-work-list.ts；CalendarPage 加 range 状态去 weekDates。
- i18n 新增区间键（rangeWeek/LastWeek/Month/LastMonth/Custom/Start/End/Prev/Next/copyList）五语言；旧 weekSummary/copyWeekList 建议保留不删。
- 【约束】月视图三栏不动、零后端改动、周一为周首、工时规则不变、单文件≤300 行不新增 disable、复用 UI 原语、五语言同步。
- 待拍板：旧键是否废弃 / 本月预设相对今天还是月视图 / 点天是否跟切周 / 翻期是否也进概览条。
