## 设计：日历周视图与工时汇总（2026-08-18 下午，设计阶段，未动代码）

### 需求
用户用日历记录每天工作，**周五集中填报工时**到公司系统；痛点是月视图格子小（每格最多 3 条）、无任何工时统计、无导出/复制通道。

### 现状核对（代码事实）
- `src/shared/calendar-types.ts`：CalendarEntry 已有 date/allDay/startTime(HH:mm)/endTime(HH:mm)/category/description → **工时可由时间段直接计算，无需改 schema**；normalize 时 start>end 已并成点事件（时长 0）。
- 存储 `src/main/custom-db/calendar-table.ts`（orca-custom.db v1），IPC `calendar:list/create/update/delete` 纯透传，main 层零改动。
- 渲染三栏：左侧分类筛选+农历+月历缩略图、中间 CalendarMonthGrid、右侧 CalendarDayPanel；工具栏月份导航+今天+新建。
- calendar-time.ts 已有 buildMonthMatrix/formatWeekdayHeaders/collectEntriesByDateKey，周一优先；holiday-data 有 isWeekendDateKey/getHolidayException（班/休徽标）。
- 分类色：meeting=amber、feature=blue、milestone=green、other=zinc；UI 原语有 ui/toggle-group.tsx 可复用做月/周切换。

### 本会话读图方式（T 类流水）
- 视觉子代理（overrides=bigmodel/glm-4.6v）报余额不足 → 智谱 API key 直连成功（`~/.zcode/v2/config.json` provider.builtin:bigmodel-coding-plan.options.apiKey，model=glm-4.1v-thinking-flash，image_url 内联 base64，实测识别出日历截图：三栏布局/4 分类色/每格 3 条/无任何工时元素）。

### 方案要点
- 工具栏加「月|周」ToggleGroup；周视图 = 7 列（周一~周日）每列当天条目**全量竖排不截断**（对比月视图 3 条截断）；周末列弱化、今天列高亮、周五列小计加重。
- 顶部周汇总条：条数 + 分类小计 + **工时合计**；「📋 复制本周清单」→ Markdown 文本（按天分组 + 每日小计 + 总计），粘贴到公司工时系统即完成周五填报。
- 工时规则：非 allDay 按时段差算，0.5h 向下取精度，end==start 不计入合计；allDay 不计工时；纯前端计算不落库。
- **可选增强（拍板项）**：① per-条目手工覆盖工时 hours 字段（v2 migration ALTER TABLE，对话框加工时输入）② 每列 8h 占比进度条 ③ 周报导出文件。推荐做①，成本约半天。
- 【约束】不改 schema（除增强①）；周一为周首；工时 0.5h 精度向下；allDay 不计；周视图全量展示；分类筛选同步生效；不新增 max-lines disable；i18n 五语言；复用现有 UI 原语不造新色。
