## 排查（Q&A，未动代码）：opencode go 套餐额度不显示（2026-08-18 下午，重踩确认）

用户反馈 orca-s 状态栏 OpenCode Go 套餐额度仍不显示（08-17 排查过同类问题）。

**根因（实证，两层）**：
1. **orca-s 的 `opencodeSessionCookie` 从安装至今存的是官方 orca 的 safeStorage 密文**（`djEwWFTe/...`，732 字符）：当前 orca-data.json 与全部 5 个 .bak（bak.0~4）字节级一致，且与官方 orca 的数据文件完全同串 → orca-s（bundle id com.penghuizhang.orca-s）解密必失败 → 内存中 cookie 为空。**safeStorage 每次加密用随机 IV：若 orca-s 曾成功写入过任何值，密文必然不同——现状证明从未写入成功（08-17 的「重新粘贴」未生效，粘贴的应是密文本体）。**
2. cookie 为空 → `src/main/rate-limits/opencode-go-usage-fetcher.ts` 返回 `Session cookie not configured` → 状态栏 `isUsageEmptyState` → 只显示 StatusBarUsageEmptyCta「Configure usage tracking」，额度条不显示。若密文侥幸进入请求，也过不了 normalizeCookieInput/parseAuthCookies（`djEw` 非 auth= 前缀、无分号、含 /+ 不匹配裸 token 规则）→ 报 `No auth cookie found`。
3. 另确认：`opencodeWorkspaceId=wrk_01KV24CRAEJNHE03EDPM7FYXMT` 已配置且格式合法，cookie 修好后抓取链路可直接用（fetcher 支持 workspace 覆盖，源头代码 4-30 已有 normalizeCookieInput，新版安装同样适用）。
