### 11. ZCode 记忆系统软链接方案 ✅
- 发现 ZCode 自动读取 `~/.zcode/cli/memories/projects/orca-xxx/memory/`
- `.workbuddy/memory/` 不会被自动读取
- 方案：在 ZCode 系统目录创建软链接，指向 .workbuddy/memory/
- 已创建软链接：MEMORY.md、daily/、active/、pitfalls/、reference/
- 验证通过：ZCode 可通过软链接正常读取所有记忆文件

## 软链接结构
```
~/.zcode/cli/memories/projects/orca-bdee74a86b8d6002/memory/
├── MEMORY.md → /Users/.../orca/.workbuddy/memory/MEMORY.md
├── daily/ → /Users/.../orca/.workbuddy/memory/daily/
├── active/ → /Users/.../orca/.workbuddy/memory/active/
├── pitfalls/ → /Users/.../orca/.workbuddy/memory/pitfalls/
└── reference/ → /Users/.../orca/.workbuddy/memory/reference/
```

## 最终架构
| 目录 | 用途 | 读取方式 |
|------|------|----------|
| `.workbuddy/memory/` | 记忆文件真实存储 | Git 提交，团队共享 |
| ZCode 系统目录 | 软链接指向真实位置 | ZCode 自动读取 |

## 升级影响
- 无影响：软链接是标准 POSIX 特性，ZCode 升级不会删除
- 如被删除：重新运行创建软链接脚本即可

## 可重复执行脚本
- 路径：`.workbuddy/scripts/setup-memory-symlinks.sh`
- 用途：ZCode 升级后重新创建软链接
- 使用：`bash .workbuddy/scripts/setup-memory-symlinks.sh`

## 增强的元数据格式

### 记忆文件新增字段
- `docs`：关联的设计文档列表
- `related`：相关的记忆文件列表
- `module`：所属模块
- `status`：状态（draft/active/archived）

### 设计文档新增字段
- `memory`：关联的记忆文件列表
- `related_docs`：相关的其他文档列表
- `module`：所属模块
- `status`：状态

## 关联规则
| 关联方向 | 触发条件 | 操作 |
|----------|----------|------|
| 记忆 → 文档 | 记忆中提到设计文档路径 | 在 `docs` 字段添加引用 |
| 文档 → 记忆 | 文档中提到相关记忆 | 在 `memory` 字段添加引用 |
| 双向关联 | 同一日期的记忆和文档 | 自动检测并建立关联 |

## 使用方式
```bash
# 自动检测关联
bash ~/.agents/skills/memory-zcode-symlink/scripts/enhance-metadata.sh

# 指定工程
bash ~/.agents/skills/memory-zcode-symlink/scripts/enhance-metadata.sh /path/to/project
```

## 关联示例

**记忆文件关联设计文档**：
