### 调研结论（关键，非显然）
**能集成，但不能像 zcode 那样直接注册 TuiAgent。** 双方模型错位：

- uni-agent 官方 CLI 是**一次性（one-shot）**命令：`cli uni-agent` 不带 `--prompt` 直接报「参数 prompt 值不能为空」并退出，**无交互式 TUI**。
- 更本质：`cli` 是 **HBuilderX 进程的本地 socket 客户端**，不是独立 runtime。证据：`strings cli` 命中 `RPC::LocalSocketClient`/`QLocalSocket::*`；HBuilderX 主进程 PID 619 监听 `127.0.0.1:9500`；模型/密钥/会话都在 HBuilderX 全局设置（`settings.json` + `api-keys.json`，`api-keys.json` 含 6 个 `UNI_AGENT_*`）。
- 会话续接靠 `--continue true` **跨进程**恢复（`project-cli-sessions.json` 记 `lastSessionId`），不是长驻进程。
- Orca 侧：`src/shared/tui-agent-startup.ts:40` 的 **6 种 promptInjectionMode 全部要求进程长驻**；`src/shared/agent-headless-command.ts:18` 只用于「识别并排除一次性命令」，**Orca 没有 one-shot agent 执行通道**。

⇒ 「像 zcode 一样用」必须加一层自研 **PTY 桥接薄壳（wrapper）**，把一次性 CLI 包装成长驻交互会话。

### Orca 集成面事实（本次核实，供复用）
- 新增 TuiAgent 需改约 15 处（见 `.workbuddy/docs/zcode/2026-08-16-新增zcode智能体类型设计方案.md`）；`ALL_TUI_AGENTS`/`KNOWN_TUI_AGENT_DETECTION_COMMANDS`/`TUI_AGENT_CONFIG` 自动派生。
- 智能体检测 = PATH 目录遍历 + `stat/access`（`src/main/ipc/command-path-resolver.ts:67`），**支持绝对路径 detectCmd**；启动 = main 进程 node-pty 在 PTY 跑 `launchCmd`（`src/main/providers/local-pty-spawn.ts:21`），**launchCmd 可为带参数的任意 shell 串**。
- 检测/启动在执行宿主本地 ⇒ HBuilderX 装在本地 app 包内 ⇒ **远端 SSH/WSL 天然不可用**。
- MCP 来源 = 只读 4 处配置文件 `src/shared/mcp-config.ts:45`（`.mcp.json`/`.cursor/mcp.json`/`.claude.json`/`.claude/mcp.json`），**Orca 不写入、无添加 UI** ⇒ MCP 路线注册需用户手改配置。
- 本仓库 i18n 实为 **6 语言**（en/es/fr/ja/ko/zh），非此前的 5 语言。
