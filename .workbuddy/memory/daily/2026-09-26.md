## 经验（可复用）

1. **AST 遍历脚本必须用大括号**：`for (…) if (…) visit(x)` 后换行接 `else`，else 会挂到内层 if，
   非数组的单对象子节点**永远不被访问**，脚本静默报「一切正常」。本轮检测器第一版就栽在这，
   在真有重复的文件上报干净——**拿已知有重复的真实文件验证脚本，是必须的**。
2. **`require('typescript')` 在 TS 7 是空壳**：Go 原生版只暴露 `version`/`versionMajorMinor`，
   没有编译器 API。用 `oxc-parser`（已在 node_modules）。
3. **`git show` 的 stage spec 不要拼第二个冒号**：`f'{rev}:{path}'` 而 `rev` 已以 `:` 结尾 ⇒
   `:1::path` 读不到东西，脚本静默降级成「只取 ours」。
4. **zsh 不对未加引号的变量分词**：`for cfg in $var` 整串成一个参数，oxlint 报莫名 FAIL。用 `${=var}`。
5. **正则扫重复必然误报**：`grep | uniq -d` 跨作用域误报 91 处；全树另有 119 处**合法**重复
   （`stdio` 的 `['ignore','pipe','pipe']`、重复 argv flag、shell 片段）⇒ 必须 AST + 基线差集。
6. **探针要先验证探针本身**：`skills add --agent <x> --list` 不校验 agent 键，合法键与瞎编的键
   输出完全相同、退出码都是 0。要搜包本体。
7. **别在有未提交改动时 `git reset --hard`**：本轮开头为复位旧同步分支跑了 `reset --hard`，
   把 2 行未提交的 TeleAgent 记忆索引清掉了（当场按原文补回）。`git branch -f` 在分支被当前
   worktree 占用时会失败，但此时 `reset` 已经改好了指针。
